# Flarum Pronouns

![License](https://img.shields.io/badge/license-GPL-3.0+-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/oliverbates/flarum-pronouns.svg)](https://packagist.org/packages/oliverbates/flarum-pronouns) [![Total Downloads](https://img.shields.io/packagist/dt/oliverbates/flarum-pronouns.svg)](https://packagist.org/packages/oliverbates/flarum-pronouns)

A [Flarum](https://flarum.org) extension. Show pronouns as user badge - rewrite of [shriker/flarum-pronouns](https://github.com/shriker/flarum-pronouns) for v2.

When the extension is enabled, pronouns are mandatory when registering; if a user doesn't have some pronouns set, they will have no pronouns badge.

## Installation

Install with composer:

```sh
composer require oliverbates/flarum-pronouns:"*"
```

## Updating

```sh
composer update oliverbates/flarum-pronouns:"*"
php flarum migrate
php flarum cache:clear
```
